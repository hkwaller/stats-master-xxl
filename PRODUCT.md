# Stats Master

An English NHL trivia game from Playam for 2–8 players using a shared board and phones. Classic, Career, Head-to-Head and Higher / Lower run in authoritative PartyServer rooms; NHL data and daily scores use Supabase. Clerk accounts are optional for guest play.

The native app extends the website with a compact /app home for hosting, joining, the daily challenge and offline Classic practice. Practice is local and never submits daily scores. Preserve the existing On the Ice / Rinkside visual system in DESIGN.md. Native identity: Stats Master, app.playam.statsmaster. Production: https://statsmaster.playam.app.
