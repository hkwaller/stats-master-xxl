# Stats Master Clerk branding

The user approved applying Stats Master’s existing navy/red identity to Clerk, using Population’s provider-level theming approach. Rename the Clerk application from NHL Stats Master to Stats Master.

Keep the native Clerk account flow and its existing behavior. Use Archivo body text, Big Shoulders headings, white surfaces, square corners, the existing red action color and navy text tokens. Apply the appearance once at ClerkProvider so modal sign-in and profile surfaces share the theme. Put the provider inside the document body so portal content inherits the app’s typography and tokens.

Validation: TypeScript, the Impeccable detector, a production build, and desktop/mobile browser inspection of the live sign-in modal. No authentication settings or game behavior change.
